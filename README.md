# tadami

只見町の事業者と大学生をつなぐ、アルバイトマッチングの仕組みづくりプロジェクトです。

## 概要

只見町の事業者と大学生が、それぞれの空いている日程・空いていない日程を共有し、日程が合うときにアルバイトを申し込めるようにします。

- **事業者 → 大学生**：大学生の空き日程を確認し、事業者からアルバイトを依頼する
- **大学生 → 事業者**：事業者の空き日程（人手が欲しい日程）を確認し、大学生から応募する

独自のシステムは開発せず、既存の日程調整ツールと LINE を組み合わせて運用します。

## 使用するツール

### 日程調整ツール（スケジュールの入力・閲覧）

https://mitani.cs.tsukuba.ac.jp/arrange2/index.php

筑波大学 三谷純先生が公開している日程調整ツールです。候補期間を設定したページを作成し、そのURLを共有するだけで、参加者がそれぞれの都合を入力・閲覧できます。

ページ作成時の主な設定項目は以下のとおりです。

| 項目 | 内容 |
| --- | --- |
| イベント名 / 作成者名 | 必須 |
| 候補期間 | 開始日〜終了日（**最大100日**） |
| 時間単位 | 1日単位、半日単位（午前/午後）、1時間単位、30分単位、授業単位 など |
| 休日の扱い | 土日を除外する / 含める |
| 回答方式 | 都合がつかない時間をチェック（×） / 都合がつく時間をチェック（〇） |
| 参加者へのメモ | 任意 |

> **注意**：候補期間は最大100日のため、運用期間に合わせて定期的にページを作り直し、新しいURLを共有する必要があります。

### LINE（周知・申し込み）

- 事業者・大学生あわせて約150名が参加する LINE グループを作成する
- グループに日程調整ツールのURLを掲載する
- 実際のアルバイトの申し込みは、**LINE の個人チャット**で当事者同士が直接行う

## 利用の流れ

```
1. 運営が日程調整ページを作成し、LINEグループにURLを共有
        ↓
2. 事業者・大学生がそれぞれ自分の日程を入力
        ↓
3. 参加者が日程調整ページで相手の空き日程を確認
        ↓
4. 日程が合う相手に、LINEの個人チャットで申し込み
        ↓
5. 当事者同士で条件を確認し、アルバイト成立
```

## メンバーと役割

| メンバー | 役割 | 内容 |
| --- | --- | --- |
| 田島 駿 | マネージャー | タスクの切り出し・割り振り、上がってきた成果物のレビュー |
| 田代 幸喜 | 実行・提案担当 | 割り振られたタスクを主導的に進め、成果物や改善案を提案する |

### タスクの進め方

1. 田島がタスクを切り出し、GitHub の Issue として作成・割り当てる
2. 田代がタスクを進め、成果物や提案を Pull Request（またはIssueへのコメント）で提出する
3. 田島がレビューし、必要に応じてフィードバックを返す
4. 承認されたものを反映し、Issue をクローズする
